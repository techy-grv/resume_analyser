# HireFlow - Beginner RAG Application

A small recruiter-facing demo built with:

- Gemini API
- LangChain
- Gemini embeddings
- FAISS
- Streamlit
- Pydantic
- python-dotenv

The application reads resumes from the `resumes/` folder and lets a recruiter paste a Job Description.

## RAG Flow

```text
Resume PDFs/DOCX
       |
       v
Extract text
       |
       v
Split into chunks
       |
       v
Gemini Embeddings
       |
       v
FAISS
       |
       |  JD
       v
Retrieve relevant resume chunks
       |
       v
Gemini
       |
       v
Candidate evaluation
```

## 1. Create a virtual environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### macOS / Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

## 2. Install dependencies

```bash
pip install -r requirements.txt
```

## 3. Configure Gemini

Copy `.env.example` to `.env`.

```text
GEMINI_API_KEY=your_actual_key
```

Get the API key from Google AI Studio.

Do not commit `.env` to Git.

## 4. Add resumes

Put PDF or DOCX resumes inside:

```text
resumes/
```

The included example resume can be replaced with your own resume set.

## 5. Run the application

```bash
streamlit run app.py
```

Open the Streamlit URL shown in the terminal.

## 6. Use the application

1. Click **Build / Rebuild Index**.
2. Paste a Job Description.
3. Select how many candidates you want to retrieve.
4. Click **Find Candidates**.
5. Review the candidate results.

## Why FAISS?

For this beginner project, FAISS keeps the setup simple because it runs locally and does not require a separate cloud database.

If the application grows, FAISS can later be replaced with Pinecone or another managed vector database.

## Important Notes

The match score is generated by the LLM from the retrieved resume evidence. It should be treated as a screening aid rather than an automated hiring decision.

For a production system, add authentication, access control, audit logging, PII protection, monitoring, better candidate deduplication, and stronger evaluation/validation before using the system in a real hiring workflow.
